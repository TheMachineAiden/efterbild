EFTERBILD — a fictional cinema website

Serve this directory with Python 3:
  python3 -m http.server 4187 --bind 127.0.0.1
Then open http://127.0.0.1:4187

No build, npm packages, internet connection or account is needed.
The interface is in Swedish. Film details and the seat demo require JavaScript.

This is a fictional concept. All films, scenes and screening times are invented.
No tickets are sold. Seat choices exist only in the current page and reset when
another film is opened. No personal information is collected or transmitted.

Assets and licences are described in PROVENANCE.txt.
